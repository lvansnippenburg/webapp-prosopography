GitHub Integration

Connect your prosopography database to GitHub for automatic version control and backup.

Step 1: Create a Personal Access Token

  1. Go to GitHub Settings → Tokens (Fine-grained)
  2. Click "Generate new token"
  3. Give it a name like "Prosopography Database"
  4. Set expiration (recommend 90 days or 1 year)
  5. Under "Repository access", select "Only select repositories"
  6. Choose: lvansnippenburg/JsonDataStorage
  7. Under "Repository permissions", set Contents to "Read and write"
  8. Click "Generate token" and copy it

About

Turncoats and Apostates

A specialized tool for managing historical prosopographical research with support for name variants, attestations, relationships, and phonetic matching. The coat of arms represents the city of Livorno, a key location in the study of religious conversion and migration in early modern Europe.
